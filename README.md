# Time Income Tracker

یک ابزار شخصی آفلاین، سبک و سریع برای مدیریت زمان کاری، ثبت فعالیت پروژه، محاسبه درآمد ساعتی و خروجی Excel.

## ویژگی‌ها
- تایمر دقیق با عملیات شروع، توقف موقت، ادامه، توقف و ذخیره، و لغو
- مدیریت پروژه با نرخ ساعتی (ریال)
- ذخیره `hourly_rate_snapshot` برای پایداری گزارش‌ها
- اپلیکیشن کاملاً مبتنی بر **System Tray** (بدون نمایش در Taskbar ویندوز)
- آیکن دائمی در System Tray + پنجره کوچک شروع سریع + کلید میانبر سراسری (پیش‌فرض Shift+Q)
- اجرای تک‌نمونه‌ای: اگر برنامه از قبل باز باشد، اجرای دوباره فقط همان پنجره قبلی را فعال می‌کند
- فونت فارسی خوانا با اولویت IranSans / IranSansX / Yekan / B Yekan و fallback امن روی Vazirmatn / Tahoma / Segoe UI
- چینش کامل راست‌به‌چپ برای پنجره اصلی، تنظیمات، فیلدها، جدول‌ها و دیالوگ‌ها
- تشخیص idle ویندوز با Windows API (`ctypes` + `GetLastInputInfo`)
- auto-pause هنگام idle
- auto-resume بعد از auto-pause: با تشخیص دوباره فعالیت موس/کیبورد، تایمر خودکار ادامه پیدا می‌کند
- توقف ایمن تایمر هنگام عدم فعالیت موس/کیبورد، استندبای یا اجرای دوباره برنامه؛ زمان خاموشی/بیکاری در رکورد محاسبه نمی‌شود
- بخش کامل Records برای مشاهده مجموع زمان و درآمد هر پروژه، فیلتر بازه زمانی، ویرایش رکورد و حذف رکوردهای اشتباه
- نوتیفیکیشن دوره‌ای هنگام فعال بودن تایمر
- خروجی Excel آماده فاکتور با جمع کل زمان و مبلغ (ریال)
- ذخیره‌سازی کامل داده در `%APPDATA%\TimeIncomeTracker`

## مسیر ذخیره داده‌ها
- Database: `%APPDATA%\TimeIncomeTracker\time_income.db`
- Logs: `%APPDATA%\TimeIncomeTracker\logs\app.log`
- تنظیمات: جدول `settings` در SQLite
- خروجی اکسل: مسیر تنظیم‌شده در Settings (پیش‌فرض `%APPDATA%\TimeIncomeTracker`)

## نیازمندی توسعه‌دهنده
- Python 3.12+
- Windows 10/11 (برای تست کامل tray/hotkey/idle)

## اجرای سورس (برای توسعه‌دهنده)
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## ساخت فایل exe
```bat
build.bat
```
یا دستی:
```bash
pyinstaller --noconfirm --onefile --windowed --name TimeIncomeTracker main.py
```
خروجی:
- `dist\TimeIncomeTracker.exe`

## دانلود نسخه exe بدون نصب Python
1. به ریپازیتوری GitHub بروید و تب **Actions** را باز کنید.
2. workflow با نام **build-windows** را انتخاب کنید.
3. آخرین اجرای موفق را باز کنید.
4. از بخش **Artifacts**، فایل **TimeIncomeTracker-Windows** را دانلود کنید.
5. فایل دانلودشده (zip) را Extract کنید.
6. فایل `TimeIncomeTracker.exe` را اجرا کنید.

> نکته: اگر یک tag مثل `v1.0.0` ساخته و push شود، همین workflow فایل `TimeIncomeTracker.exe` را علاوه بر Artifacts، داخل **GitHub Releases** هم آپلود می‌کند.

## نکته مهم برای کاربر نهایی
**کاربر نهایی نیازی به نصب Python، pip یا ابزار توسعه ندارد و فقط فایل `TimeIncomeTracker.exe` را اجرا می‌کند.**

## رفتار پنجره و System Tray
- برنامه بعد از اجرا همیشه آیکن Tray را نگه می‌دارد (چه پنجره باز باشد چه مخفی).
- اگر برنامه از قبل اجرا شده باشد، اجرای دوباره نمونه جدید نمی‌سازد و همان پنجره قبلی را باز/فعال می‌کند.
- پنجره اصلی در Taskbar ویندوز نمایش داده نمی‌شود.
- بستن پنجره با دکمه `X` برنامه را نمی‌بندد و فقط پنجره را مخفی می‌کند.
- با کلیک چپ روی آیکن Tray، یک پنجره کوچک کنار همان گوشه باز می‌شود تا پروژه را انتخاب کنید، توضیحات بنویسید و تایمر را شروع کنید.
- فلش گوشه پنجره کوچک و دابل‌کلیک روی آیکن Tray، پنجره اصلی را به صورت بزرگ‌شده باز می‌کند.
- با گزینه `باز کردن / نمایش` در منوی Tray هم پنجره اصلی باز می‌شود.
- خروج کامل فقط از طریق گزینه `خروج` در منوی Tray انجام می‌شود.
- اگر تایمر فعال باشد و `خروج` بزنید، قبل از خروج پیام تأیید نمایش داده می‌شود.
- گزینه `نمایش پنجره اصلی هنگام اجرا` در تنظیمات تعیین می‌کند پنجره هنگام اجرا خودکار نمایش داده شود یا خیر (پیش‌فرض: غیرفعال).

## قرار دادن آیکن کنار شبکه، صدا و ساعت ویندوز
- برنامه آیکن خود را در System Tray ثبت می‌کند، اما محل دقیق آیکن‌ها در کنار آیکن‌های شبکه/صدا/ساعت توسط خود Windows مدیریت می‌شود و برنامه نمی‌تواند آن را اجباری جابه‌جا کند.
- برای کمترین درگیری، در Windows 10/11 روی فلش `^` کنار ساعت کلیک کنید و آیکن **ردیاب زمان و درآمد** را با ماوس بکشید و کنار آیکن‌های شبکه یا صدا رها کنید. بعد از این کار آیکن همان‌جا می‌ماند و با یک کلیک پنجره برنامه باز می‌شود.
- مسیر جایگزین در تنظیمات ویندوز: **Settings > Personalization > Taskbar > Other system tray icons**، سپس نمایش آیکن برنامه را روشن کنید.
- اگر نمی‌خواهید سراغ Tray بروید، کلید میانبر سراسری پیش‌فرض `Shift+Q` سریع‌ترین راه باز/مخفی کردن پنجره است و از بخش تنظیمات قابل تغییر است.

## مدیریت رکوردها
- تب **رکوردها** داخل برنامه، خلاصه پروژه‌ها را در بازه انتخابی نشان می‌دهد: تعداد رکورد، مجموع زمان و مجموع درآمد (ریال).
- جدول رکوردها جزئیات هر رکورد را نشان می‌دهد: تاریخ شمسی، پروژه، شرح، زمان شروع/پایان، مدت، نرخ ساعتی (ریال) و مبلغ (ریال).
- با دکمه **ویرایش انتخاب‌شده** یا دابل‌کلیک روی رکورد می‌توانید پروژه، شرح، زمان شروع/پایان، نرخ و مبلغ ریالی را اصلاح کنید.
- با دکمه **حذف انتخاب‌شده** می‌توانید رکوردهای اشتباه را بعد از تأیید حذف کنید.
- در تنظیمات > پروژه‌ها، ستون شناسه مخفی است، وضعیت پروژه با دکمه روشن/خاموش تغییر می‌کند، و دکمه **مشاهده گزارش** مستقیم به گزارش همان پروژه در تب رکوردها می‌رود.

## جلوگیری از ثبت زمان بیکاری، استندبای و خاموشی
- اگر موس/کیبورد به مدت تنظیم‌شده در تنظیمات غیرفعال باشد، تایمر خودکار متوقف می‌شود و زمان بیکاری از مدت کار حذف می‌شود.
- بعد از همین توقف خودکار، با حرکت موس یا فشردن کیبورد، تایمر خودکار ادامه پیدا می‌کند و ادامه زمان از همان لحظه فعالیت جدید محاسبه می‌شود.
- اگر سیستم به استندبای برود، خاموش شود، قفل شود یا برنامه بعداً دوباره اجرا شود، تایمر در حالت Pause بازیابی می‌شود تا زمان خارج از فعالیت واقعی به رکورد اضافه نشود.
- هنگام فعال بودن تایمر، برنامه وضعیت فعلی را مرتب در دیتابیس ذخیره می‌کند تا در صورت خاموشی ناگهانی، آخرین زمان ثبت‌شده قابل بازیابی باشد.

## اجرای خودکار در نسخه Portable
- برای نسخه portable، گزینه **اجرای خودکار با ویندوز** در تنظیمات بدون نیاز به admin کار می‌کند.
- با فعال‌کردن این گزینه، برنامه یک shortcut از `TimeIncomeTracker.exe` فعلی در Startup کاربر می‌سازد:
  - `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\TimeIncomeTracker.lnk`
- با غیرفعال‌کردن آن، همان shortcut حذف می‌شود.
- اگر `exe` را جابه‌جا کنید، کافی است Auto-start را یک‌بار خاموش/روشن کنید تا shortcut با مسیر جدید ساخته شود.
- چون برنامه portable است، بهتر است `TimeIncomeTracker.exe` را در یک مسیر ثابت نگه دارید (مثلاً `C:\Apps\TimeIncomeTracker`).

## عیب‌یابی
- اگر کلید میانبر ثبت نشد: برنامه ادامه می‌دهد و خطا در وضعیت/log نمایش داده می‌شود.
- اگر اعلان محدود بود: برنامه با پیام جایگزین Tray اجرا می‌شود.
- اگر Excel خروجی نداد: مسیر خروجی و سطح دسترسی پوشه را بررسی کنید.
- اگر دیتابیس نبود: برنامه خودکار جدول‌ها را ایجاد می‌کند.
